# Rooted

**Bioregional intelligence for your place.**

Rooted is a Progressive Web App that gives you practical, location-aware guidance for growing food, managing water, reducing heat risk, and coordinating small regenerative projects with neighbours.

## Features

- **Bioregion status** — Temperature, soil moisture outlook, wind, water restrictions tailored to your area
- **Prioritised daily actions** — Time-sensitive growing advice and local opportunities
- **Scan** — Photograph a plant for identification and place-specific diagnosis
- **Household resilience** — Track water security, food production potential, and heat vulnerability
- **Community** — Discover nearby people open to plant swaps and join local regenerative missions

## Demo locations

Currently includes:
- Cape Town (Southern Suburbs)
- Johannesburg (Northern Suburbs)
- Durban (Berea)
- Pretoria (Eastern Suburbs)
- Stellenbosch

## Tech

- Pure HTML / CSS / vanilla JavaScript
- No build step
- Works offline as a PWA
- Local storage for persistence
- Fully client-side (easy to deploy anywhere)

## Deploy

Just upload the contents of this repository to any static host:

- **Netlify** — drag & drop the folder
- **Vercel** — `npx vercel`
- **GitHub Pages** — enable in repo settings
- Any Apache / Nginx / S3 / Cloudflare Pages static site
